# Сайт мастерской по телу «Cuerpo», Тольятти

Чистый HTML5 + CSS + vanilla JS, без фреймворков. Главная страница плюс
отдельные страницы направлений и услуг — всё статическое, сервер не нужен.

```
cuerpo-demo/
├── index.html          ← главная
├── 404.html            ← страница «такой страницы нет» (собирается скриптом)
├── uslugi/             ← страницы направлений и услуг (собираются скриптом)
│   └── spa-programmy/
│       ├── index.html          ← направление: список услуг
│       └── relax/index.html    ← услуга: цена, описание, запись
├── sertifikaty/        ← подарочные сертификаты
├── sitemap.xml         ← карта сайта для поисковиков
├── assets/
│   ├── style.css       ← стили всего сайта
│   ├── app.js          ← скрипты всего сайта, здесь же ссылка на онлайн-запись
│   ├── favicon.svg     ← иконка вкладки (+ favicon-32.png, apple-touch-icon.png)
│   ├── img/            ← картинки, все в webp; отдельно og-cover.jpg для соцсетей
│   └── source/         ← исходные скриншоты (не публикуются)
├── tools/
│   ├── data.py         ← ВСЕ услуги: цены, описания, фото
│   ├── build.py        ← сборщик страниц
│   ├── brand.py        ← обложка для соцсетей и иконки вкладки
│   ├── webp.py         ← перевод фотографий в webp
│   └── check.py        ← проверка собранного сайта перед публикацией
└── _drafts/            ← прошлые версии (не публикуются)
```

## 0. Как менять услуги и цены

**Единственное место, где живут данные об услугах, — `tools/data.py`.**
Оттуда собираются страницы услуг, плашки на главной, лента популярных услуг,
микроразметка и карта сайта.

1. Откройте `tools/data.py`, найдите нужную услугу и поправьте `price_full`,
   `txt`, `lead`, `inc`, `eff` или что нужно.
2. Соберите сайт заново — в Терминале, из папки проекта:

```bash
python3 tools/build.py
```

Скрипт перезапишет страницы в `uslugi/` и `sertifikaty/`, блок услуг и
микроразметку на главной, `404.html` и `sitemap.xml`. Python 3 уже стоит на
macOS — ставить ничего не нужно.

> **Важно.** Всё, что между метками `<!-- BUILD:services -->` и `<!-- BUILD:ld -->`
> в `index.html`, и всё содержимое папок `uslugi/` и `sertifikaty/` собирается
> автоматически. Ручные правки там потеряются при следующей сборке — правьте
> `tools/data.py`.

Шапка, меню и подвал берутся из `index.html`: поправили их на главной,
запустили сборку — обновились на всех страницах.

### Что проверить после правок

```bash
python3 tools/check.py
```

Скрипт пройдёт по всем собранным страницам и скажет, если появились незакрытые
теги, битые пути к картинкам, одинаковые `title` или `description`, картинки без
`alt` или без отложенной загрузки, кнопка записи без привязки к YClients или
сломанная микроразметка. Молчит — значит всё в порядке.

### Если добавили или заменили фотографии

Положите исходники в `assets/img/`, затем:

```bash
python3 tools/webp.py --clean   # перевести в webp и удалить исходники
python3 tools/brand.py          # пересобрать обложку для соцсетей и иконки
```

В `tools/data.py` у каждой картинки указаны реальные ширина и высота файла —
если поставили другое фото, поправьте и их, иначе поедет вёрстка.

|---|---|---|

| **Промокод «ПЕРВЫЙ» и цены со скидкой** | `tools/data.py`, поле `promo` у 4 услуг | **демо-заглушка, салон акции не объявлял** |
| Длительность услуг | `tools/data.py`, поле `dur` | проставлена ориентировочно |
| Ссылка на карточку в 2ГИС | `CONFIG.gisUrl` | сейчас поиск по названию |
| **Адрес салона и часы работы** | `index.html`: секция «Контакты», подвал, мобильное меню, `description` | **не подтверждены клиентом** — из микроразметки убраны, на страницах остались |

### Как заменить заглушку на фото

1. Положите файл в `assets/img/`, например `interior-1.jpg`.
2. В `index.html` найдите блок с комментарием и замените

```html
<div class="ph"><span>…</span></div>
```

на

```html
<img src="assets/img/interior-1.jpg" alt="Кабинет массажа в салоне Cuerpo в Тольятти" loading="lazy">
```

**Про alt:** он важен для поиска — пишите по-человечески и с гео-словом: «Кедровая бочка в массажном салоне Cuerpo, Тольятти».

**Про размер:** фото шире 1600 px лучше уменьшить (Просмотр → Инструменты → Настроить размер), иначе сайт будет грузиться медленнее.

## 2. Онлайн-запись

Сайт **не собирает персональные данные**: формы с именем и телефоном на нём
нет. Все кнопки «Записаться» ведут в онлайн-календарь салона в YClients, там
человек сам выбирает услугу, мастера и время. Поэтому политика обработки
персональных данных и согласие на обработку сайту пока не требуются.

**Ссылка живёт в одном месте** — в начале `assets/app.js`, объект `CONFIG`:

```js
booking: 'https://n908364.yclients.com/company/845911/personal/menu?o=',
```

Скрипт сам проставляет её всем элементам с атрибутом `data-book` и добавляет
`target="_blank"` — в разметке адрес не продублирован ни разу.

### Отдельная ссылка на конкретную услугу или мастера

Когда в YClients появятся прямые ссылки, допишите их в те же настройки —
разметку править не нужно:

```js
bookingByService: {
  'Классический массаж спины': 'https://n908364.yclients.com/company/845911/personal/menu?o=s12345',
},
bookingByMaster: {
  'Татьяна': 'https://n908364.yclients.com/company/845911/personal/menu?o=m678',
},
```

Ключ — точное имя услуги из `tools/data.py` (оно попадает в атрибут
`data-service`) или имя мастера из блока команды (`data-master`). Для чего нет
своей ссылки, работает общая.

### Прилипающая кнопка на мобильном

Внизу экрана появляется панель «Записаться на сеанс» — на главной после того,
как первый экран уехал вверх, на внутренних страницах сразу после шапки. На
десктопе панель скрыта. Порог задан в `assets/app.js`, функция `mbarThreshold`.

## 2а. Живые отзывы из Яндекс Карт и 2ГИС

Сейчас в блоке отзывов стоят реальные тексты с Яндекс Карт, вбитые вручную, плюс кнопки «Отзывы на Яндексе» и «Отзывы в 2ГИС». Чтобы отзывы подтягивались сами и обновлялись:

1. Зарегистрируйте карточку салона на **repometr.com** (именно такой виджет вы видели на сайте LEGCHE) — он собирает отзывы из Яндекс Карт, 2ГИС и Google в один блок.
2. Скопируйте код виджета.
3. В `index.html` найдите комментарий `МЕСТО ПОД ВИДЖЕТ ЖИВЫХ ОТЗЫВОВ` в секции отзывов и раскомментируйте блок под ним, вставив код виджета внутрь:

```html
<div class="rwidget reveal">
  … код виджета сюда …
</div>
```

Свои карточки при этом можно оставить — они грузятся мгновенно и подстрахуют, если виджет не отвечает.

## 2б. Карта на странице контактов

Карта уже встроена (виджет Яндекс Карт по адресу Приморский бульвар, 57). Под ней лежит запасной слой с адресом — он виден, только если карта не загрузилась.

## 4. Как опубликовать

**Демо уже опубликовано** на GitHub Pages: <https://leragodzen.github.io/cuerpo-demo/>

Чтобы выложить новую версию после правок — двойной клик по файлу
`Опубликовать демо Cuerpo.command` на Рабочем столе (перед этим скопировать
токен с github.com/settings/tokens). Скрипт сам создаст репозиторий, если его
нет, отправит файлы и включит Pages.

> **Демо закрыто от поисковиков.** В `index.html` стоит
> `<meta name="robots" content="noindex, follow">` — чтобы демо-версия с
> реальным названием и телефоном салона не конкурировала в выдаче с будущим
> настоящим сайтом Cuerpo. По прямой ссылке сайт открывается как обычно.
> Перед сдачей реальному клиенту: поменять `noindex` на `index` в `index.html`
> и запустить `python3 tools/build.py` — значение разойдётся по всем страницам.

### Другие варианты хостинга

Сайт статический, поэтому подойдёт любой хостинг:

- **Быстро и бесплатно:** [Netlify Drop](https://app.netlify.com/drop) — перетащите папку целиком в окно браузера, получите ссылку за минуту. Удобно, чтобы показать клиенту.
- **Для продакшена:** обычный хостинг (Timeweb, Reg.ru, Beget) — залейте содержимое папки в корень сайта по FTP.

После публикации:
1. Добавьте сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru/) и укажите его в карточке организации в Яндекс Бизнесе — это усилит и сайт, и карточку.
2. Проверьте микроразметку: [валидатор Яндекса](https://webmaster.yandex.ru/tools/microtest/).
3. Проверьте скорость: [PageSpeed Insights](https://pagespeed.web.dev/).

## 5. Что уже сделано под SEO

- `<title>` и `description` с ключами «массажный салон Тольятти», «запись на массаж», адресом
- Один `H1`. Название салона напечатано прямо на фото первого экрана, поэтому текстовый `H1` спрятан от глаз, но виден поиску и скринридерам — искать `sr-only` в начале секции `hero`. Слово «Тольятти» убрано из видимых заголовков, но осталось в `title`, `description`, `alt` и микроразметке
- Логичная структура `H2/H3` с гео-ключами («в Автозаводском районе», «Приморский бульвар, 57»)
- Микроразметка **Schema.org JSON-LD**: `HealthAndBeautyBusiness` + `DaySpa` — адрес, телефон, часы, координаты, диапазон цен, рейтинг 5,0 и весь каталог услуг с ценами
- Отдельная разметка **FAQPage** — блок вопросов может показаться прямо в выдаче
- `alt` у всех изображений, `loading="lazy"` у всего, кроме первого экрана

## 6. Маркетинговая логика страницы

Порядок блоков собран как воронка: **внимание → доверие → выбор → доказательство → действие**.

1. **Первый экран** — фото-макет салона во всю ширину: логотип, кадр массажа и подписи-выноски напечатаны прямо на снимке, под ним настоящая кнопка «Смотреть услуги»
2. **Полоса фактов** — 5,0 · 1000+ клиентов · адрес · часы работы: доверие в первые секунды
3. **Почему к нам возвращаются** — четыре карточки с подсветкой: почему сюда, а не в соседний салон
4. **О мастерской** — короткий текст и цитата, без длинной простыни
5. **Три принципа** — тёмный блок про то, как устроена работа с телом
6. **До / после** — доказательство результата, интерактивный ползунок держит внимание
7. **Услуги** — шесть зелёных плашек-направлений. В каждой видна одна главная услуга, остальные раскрываются кнопкой: человек не тонет в прайсе
8. **«Не знаете, что выбрать?»** — тёмный блок с телефоном и формой обратного звонка: ловит тех, кто не выбрал сам
9. **Сертификат** — отдельный блок: второй способ купить, даже если человек не готов идти сам
10. **Мастера** — лица и характеры, кнопка записи к конкретному мастеру
11. **Отзывы** — 5,0, награда «Хорошее место», реальные тексты и ссылки на Яндекс и 2ГИС
12. **Атмосфера, «как проходит визит», FAQ** — снимают страх первого визита
13. **Контакты с картой** — действие

Сквозные точки входа: кнопка в шапке, липкая панель на телефоне, кнопка у каждой услуги и каждого мастера, форма обратного звонка — записаться можно из любой точки страницы.

## 7. Что изменилось в демо-версии

Демо собрано из проекта `cuerpo-massage-2`, исходник не тронут.

- **Запись целиком в YClients.** Форма заявки, модальное окно, форма обратного
  звонка и модалка политики убраны — сайт не собирает персональные данные.
  Ссылка на онлайн-календарь лежит одной константой в `assets/app.js`
- Нижняя панель «Записаться» на мобильном появляется после первого экрана,
  а не после первых 140 пикселей прокрутки
- Контакты приведены к данным салона: телефон в `tel:`, ВКонтакте на `vk.ru`,
  Telegram, MAX по ссылке-приглашению, карточка на Яндекс Картах. Иконки
  соцсетей продублированы в подвале, там же реквизиты ИП
- Микроразметка `LocalBusiness` собирается из `tools/data.py`, поэтому цены в
  ней не расходятся с каталогом. Адрес и часы работы пропущены — нет данных
- Все фотографии переведены в webp: 3,4 МБ → 1,5 МБ. Отложенная загрузка у
  всех картинок, кроме первого экрана
- Обложка для мессенджеров 1200×630 (`assets/img/og-cover.jpg`) и иконки
  вкладки — собираются скриптом `tools/brand.py`
- Страница `404.html` в стиле сайта, с кнопками на главную и в каталог. Пути
  к стилям и картинкам в ней абсолютные — сервер отдаёт эту страницу по любому
  несуществующему адресу, и относительные пути указывали бы в никуда. Из-за
  этого при локальном просмотре она выглядит без оформления, а на опубликованном
  сайте — нормально. Поменяли домен — обязательно поправьте `SITE` в
  `tools/build.py` и пересоберите, иначе 404 останется без стилей
- Блоки, которые проявляются при прокрутке, теперь видны и без JavaScript
  (раньше страница без скриптов оставалась пустой)
- Добавлен `tools/check.py` — проверка собранного сайта перед публикацией
